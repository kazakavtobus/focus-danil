# FOCUS — Stay Focused

**Личное пространство прогресса для Windows 11.** Тёмный изумрудный Apple-inspired интерфейс, ежедневные привычки, вес, еженедельные замеры и фотоархив. Офлайн по умолчанию. Все личные записи и фотографии остаются на компьютере, а **обновления приложения приходят через GitHub Releases**.


## Что есть внутри

- Каждый день: ориентир **1800 ккал**, дорожка **60 минут** (можно частями), без алкоголя, сон **7–9 часов**, заправленная постель, порядок на рабочем месте, подъём к **09:00**, не есть после **21:00**. Цели можно менять в настройках.
- Вес: старт **89,1 кг** на **02.11.2026**, первая цель **80 кг**; шкала, график, история.
- Еженедельные измерения, заметки, фотографии лица/тела, просмотр и сравнение двух дат.
- Локальные данные, экспорт/импорт резервной копии вместе с фотографиями.
- Windows: трей, опциональный автозапуск, системные уведомления и мягкий сигнал.
- **Настройки → Обновления FOCUS**: «Проверить обновления» → «Скачать обновление» → «Установить и перезапустить». Установка **не удаляет** пользовательские данные.

## Первое размещение в GitHub и установка EXE

Нужен **публичный** GitHub-репозиторий. Фотографии и личная история в него не загружаются, но **стартовые цели и имя по умолчанию находятся в открытом исходном коде**. Если хочешь скрыть даже их — измени исходники до публикации или используй другой способ распространения обновлений.

1. Создай в [GitHub](https://github.com/new) **пустой публичный репозиторий**, например `FOCUS`. Не добавляй автоматически README, `.gitignore` или лицензию: всё нужное уже есть в проекте.
2. Распакуй ZIP с исходниками в новую папку. Открой терминал (PowerShell / Git Bash) **внутри** этой папки и выполни команды ниже, заменив `USERNAME` на свой GitHub-логин.

   ```powershell
   git init -b main
   git add .
   git commit -m "FOCUS 1.1.0: GitHub updates"
   git remote add origin https://github.com/USERNAME/FOCUS.git
   git push -u origin main
   git tag v1.1.0
   git push origin v1.1.0
   ```

   Должен быть установлен [Git for Windows](https://git-scm.com/downloads/win). Если GitHub запросит вход, используй его обычную авторизацию, не вставляй пароль в команды.

3. Открой вкладку **Actions** на GitHub, дождись завершения workflow **Publish Windows release**. GitHub сам определит твой `USERNAME/FOCUS` и встроит адрес репозитория в Windows-сборку. Если Actions отключены — включи их для репозитория.
4. Открой **Releases → v1.1.0**. Скачай **`FOCUS-Setup-1.1.0-x64.exe`**, установи и запусти приложение.
5. В FOCUS открой **Настройки → Обновления FOCUS**. До выхода следующего релиза кнопка ответит, что установлена последняя версия.

**Не устанавливай portable-версию вместо NSIS-инсталлятора**, если хочешь обновления одной кнопкой: автообновление поддерживает именно установленная Windows-версия.

> **Важно:** первый EXE и автоматические обновления заработают только после реального успешного билда в GitHub Actions и публикации Release. Этот репозиторий — исходный код; готового EXE внутри ZIP нет.

## Как выпускать следующие версии

Когда мы внесём доработки в FOCUS, для примера выпуска **1.1.1**:

1. Замени нужные файлы проекта на обновлённые. Измени поле `version` в `package.json` на `1.1.1` (номер **обязательно** выше текущего).
2. Сохрани новую версию в GitHub:

   ```powershell
   git add .
   git commit -m "FOCUS 1.1.1 improvements"
   git push origin main
   git tag v1.1.1
   git push origin v1.1.1
   ```

3. GitHub Actions соберёт новую версию и создаст Release c `latest.yml`, установщиком и нужными файлами обновления. Приложение версии 1.1.0 сможет найти 1.1.1 через **Настройки → Проверить обновления**.

Нельзя использовать один и тот же тег/номер повторно. Если меняешь GitHub-репозиторий после первого релиза, старые установки продолжат смотреть на прежний адрес — заранее продумай перенаправление пользователей.

## Запуск исходников и локальная сборка

Для разработки установи [Node.js LTS](https://nodejs.org/), затем запусти `START_FOCUS.bat` или:

```powershell
npm install
npm start
```

Проверка логики обновлений без скачивания Electron:

```powershell
npm run check
npm test
```

Локальная сборка Windows-инсталлятора (перед этим укажи репозиторий, чтобы внутри оказалась правильная ссылка на GitHub):

```powershell
npm run github:configure -- USERNAME/FOCUS
npm install
npm run build:win
```

Результат будет в `release/`. Скрипт `BUILD_WINDOWS_EXE.bat` также запрашивает адрес репозитория и выполняет сборку на Windows. **В режиме `npm start` кнопка обновлений недоступна**, это ожидаемо.

### Браузерное демо

Открой `FOCUS-demo.html` (или `index.html` в Chrome/Edge). Демо не поддерживает системные уведомления, автозапуск и обновление программы. Для постоянного фотоархива используй Windows-версию, потому что у браузерного `localStorage` небольшой лимит.

## Приватность и сохранность данных

- В установленном приложении данные хранятся в `app.getPath('userData')`; точный путь показан в Настройках. Фотографии — во вложенной папке `photos/`. **GitHub не получает данные трекера.**
- Исходные имя продукта, `name` пакета и `appId` оставлены как в предыдущей версии — это важно, чтобы следующая установка находила прежнюю пользовательскую папку.
- Перед первой установкой или крупным обновлением можно сделать **Настройки → Экспорт**. JSON-бэкап включает фотографии: не загружай его в публичный репозиторий.
- `.gitignore` исключает типичные личные файлы, фото, бэкапы и сборки. Но **перед `git add` проверь содержимое**, особенно если ты вручную копировал туда личные файлы.
- При установке без цифровой подписи Windows SmartScreen может показать предупреждение «неизвестный издатель». Для распространения другим людям рекомендуется подпись кода; GitHub не подписывает EXE автоматически.

## Как устроены обновления

- `electron-updater` использует GitHub-провайдер, который `electron-builder` встраивает в установленное приложение при сборке. Это **не произвольное скачивание ZIP и не установка из исходного кода**.
- GitHub Action `.github/workflows/release.yml` по тегу `v<версия>` запускается на Windows, устанавливает зависимости, проверяет код, собирает NSIS EXE и публикует Release с `latest.yml` и `.blockmap`.
- Проверка запускается вручную. Пока скачивание идёт, отображается процент; перезапуск только после нажатия «Установить и перезапустить».
- Требуется интернет и доступ к публичному GitHub Releases. В приватном репозитории такое обновление из обычного приложения **не заработает** без отдельной защищённой схемы доступа; не встраивай персональные токены в исходники.

**Безопасность и здоровье:** FOCUS — трекер привычек, а не медицинская рекомендация. Цели 1800 ккал и 60 минут заданы пользователем и редактируются. При высоком давлении, головных болях, кровотечениях или плохом самочувствии не стоит пытаться выполнить тренировочный план любой ценой — интенсивность лучше согласовать с врачом.

## FOCUS 1.1.1 — адаптивное окно

- Собственная изумрудная панель окна: перетаскивание, свернуть, развернуть/восстановить, скрыть в трей (полный выход через трей).
- Тонкая полупрозрачная полоса прокрутки.
- Минимальная ширина 700 px, адаптивные сетки и карточки, боковая панель при низком окне.
- Локальные записи и фотографии остаются без изменений.
